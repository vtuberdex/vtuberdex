# Plan: Rediseño de la carta 3D — fondo con paralaje + holograma, personaje sólido, UI limpia

## Goal

Reestructurar las 7 capas de la carta 3D para que el fondo sea la textura del mesh CON paralaje propio y holograma fuerte, el personaje se vea sólido (solo edge-holograma mínimo), y la UI quede reducida a título opaco + wordmark izquierdo + logo grande abajo-derecha.

## Current context / assumptions

- **7 capas** con paralaje independiente: 0=surface, 1=character, 2=logo(vacía), 3=title, 4=texts, 5=tags, 6=wordmark. Definidas en `components/card3d-config.ts:1001` (`PARALLAX_LAYERS`).
- **Capa 0** hoy es opaca y tiene factor de paralaje `0` (anclada al mesh). El usuario ahora pide que SÍ tenga paralaje.
- **Shader** en `components/shaders.ts` (~1340 líneas, template literal TS): mezcla las capas con `mix()`, aplica barniz + holograma + edge + metal a `base`, y recompone el logo como sticker al final.
- **`surfaceZone`** (L938): escala los efectos por `1 - uiCover`, donde `uiCover = max(layer3..6.a)`. Hoy el holograma se aplica a toda la superficie menos la UI.
- **Logo**: se dibuja como sticker al final del shader (L1191-1234), posicionado via `logoBox` calculado en `componer.ts:49-56`. La capa 2 va vacía a propósito.
- **Wordmark**: `capa-wordmark.ts:22` — `drawMetalWordmark(ctx, 'VTUBERDEX', W - pad, H - 86, ...)` alineado a la derecha. Hay que moverlo a la izquierda.
- **Textos y tags**: `capa-textos.ts` (chips de estado, frase, pie) y `capa-tags.ts` (chips de facciones/grupos + barra de stats). El usuario pide eliminarlos del card 3D.
- **`holo-card.tsx`** genera las texturas (L200-247), las sube como uniforms, y en `useFrame` (L402-465) actualiza los uniforms vivos. Los textos/tags se eliminan pero los slots 4 y 5 NO se pueden renumerar (rompería `uLayer4`/`uLayer5` y `PARALLAX_LAYERS`).
- **Trampa crítica**: `shaders.ts` es un template literal — NUNCA usar backticks en comentarios GLSL.
- **Trampa crítica**: el límite de samplers es 16; hoy hay 14-15 activos. No añadir samplers nuevos.
- **Trampa crítica**: `npm run build` con dev server vivo = `.next` mezclado = carta negra. Parar dev antes de build.
- **Gates obligatorios**: `npm run lint && npm run typecheck && npm run check:shaders && npm run build && npx vitest run && cd server && npm test && cd ../scraper && npm test`.
- Solo 1 carta (`corny-holocean`) tiene background subido. El resto muestra solo el degradado de tema.

## Architecture / proposed approach

1. **Fondo con paralaje**: cambiar `PARALLAX_LAYERS[0].factor` de `0` a un valor positivo (ej. `0.04`) y subir `BACKGROUND.cover` para que el desplazamiento no descubra el borde. El holograma del fondo ya existe (bloque "CAPA 0B" en L763-776 con `uBgHolo` etc.); se refuerza subiendo `BACKGROUND.holo` y `BACKGROUND.layerWeight`.
2. **Personaje sólido**: hoy el personaje recibe holograma global via `holoLayer *= surfaceZone * sinLogo`. Hay que enmascarar el holograma para que SOLO caiga en los edges del personaje (usar `uEdgeMap` que ya existe + `layer1.a` como silueta), y reducir `holoLayer` sobre el interior del personaje.
3. **UI limpia**: vaciar las capas 4 (texts) y 5 (tags) → `emptyLayer()`. Mover wordmark a la izquierda. Hacer el título opaco (sin translucidez). Mover y agrandar el logo.

### Task 3: Personaje sólido — holograma solo en edges

**Archivos**: `components/shaders.ts`

**Contexto**: Hoy (L941-942):
```glsl
glossLayer *= surfaceZone;
holoLayer *= surfaceZone * sinLogo;
```

El `holoLayer` cae sobre toda la superficie (menos UI). Hay que hacer que el holograma SOLO caiga sobre los edges del personaje y sobre el fondo, NO sobre el interior del personaje.

**Cambios** en el bloque de `surfaceZone` (L937-943):

Reemplazar:
```glsl
    float uiCover = max(max(max(layer3.a, layer4.a), layer5.a), layer6.a);
    float surfaceZone = 1.0 - uiCover;

    glossLayer *= surfaceZone;
    holoLayer *= surfaceZone * sinLogo;
    edgeLayer *= surfaceZone * sinLogo;
```

Por:
```glsl
    float uiCover = max(max(max(layer3.a, layer4.a), layer5.a), layer6.a);
    float surfaceZone = 1.0 - uiCover;

    /**
     * El PERSONAJE debe verse SOLIDO: el holograma global solo cae sobre el
     * fondo (donde no hay personaje) y sobre los EDGES del personaje (donde la
     * silueta cambia de 0 a 1). El interior del personaje recibe barniz pero
     * NADA de holograma, para que su color y contraste se lean intactos.
     *
     * edgeTex (uEdgeMap) es la mascara de lineart/piel calculada en CPU: vale
     * ~1 en los bordes del personaje y 0 en su interior. Combinarla con
     * layer1.a (la silueta) da una mascara que solo enciende en los edges.
     */
    float charEdgeMask = edgeTex.a * layer1.a;
    float charInterior = layer1.a * (1.0 - charEdgeMask);
    float holoZone = surfaceZone * (1.0 - charInterior);

    glossLayer *= surfaceZone;
    holoLayer *= holoZone * sinLogo;
    edgeLayer *= surfaceZone * sinLogo;
```

**Verificación**:

Reemplazar la función completa por:
```ts
export function drawMetalWordmark(
  ctx: CanvasRenderingContext2D,
  text: string,
  left: number,
  y: number,
  font: string,
  brand: string,
): void {
  const { wordmark } = TEXT_FINISH;
  ctx.save();
  ctx.font = font;
  ctx.textAlign = 'left';
  ctx.textBaseline = 'middle';
  ctx.fillStyle = rgba('#05060a', wordmark.bevelDarkAlpha);
  ctx.fillText(text, left, y + wordmark.bevelDarkOffset);
  ctx.fillStyle = rgba('#ffffff', wordmark.bevelLightAlpha);
  ctx.fillText(text, left, y + wordmark.bevelLightOffset);
  const textWidth = ctx.measureText(text).width;
  const g = ctx.createLinearGradient(left, y - 16, left + textWidth, y + 16);
  for (const s of wordmark.stops) g.addColorStop(s.at, mixHex(s.color, brand, wordmark.brandTint));
  ctx.fillStyle = g;
  ctx.fillText(text, left, y);
  ctx.restore();
}
```

## Risks, tradeoffs, and open questions

1. **Paralaje del fondo puede descubrir el borde**: con `factor: 0.04` y `cover: 1.25`, el desplazamiento máximo es 4% del ancho de carta. El `cover` de 1.25 deja 12.5% de margen por lado, suficiente. Si se ve el borde, subir `cover` a `1.3`.
2. **Eliminar texts/tags rompe el `info` que usan otros componentes**: `CardLayers['info']` expone `typesTop`, `phraseBottom`, etc. Si otros componentes leen `info`, pueden fallar. **Verificar con `grep`** antes de eliminar. Si nada fuera de `componer.ts` lee `info`, es seguro.
3. **El sticker del logo depende de `logoBox`**: al cambiar la posición y tamaño del logo, el sticker y la máscara se recalculan automáticamente. Pero el paralaje del logo (`uLogoParallax = -0.03`) podría hacer que un logo más grande se salga del borde. **Verificar visualmente**.
4. **`edgeTex` (uEdgeMap) se calcula sobre el `flatCanvas`** que incluye texts y tags. Al eliminarlos, el `flatCanvas` cambia y la máscara de edges del personaje puede variar ligeramente. Como los texts/tags no se solapan con el personaje, el impacto es nulo, pero conviene verificar.
5. **El holograma "fuerte" del fondo puede lavar una imagen clara**: `artFloor: 0.7` conserva el 70% del color original. Si el fondo del acuario pierde demasiado detalle, subir `artFloor` a `0.8`.
6. **`drawMetalWordmark` se usa solo en `capa-wordmark.ts`**: el cambio de alineación es seguro. Verificar con `grep -rn 'drawMetalWordmark'`.
7. **Punto 5 del usuario ("eliminar todos los textos en blanco")**: se interpretó como "eliminar del card 3D las capas de textos (chips de estado, frase, pie) y tags (facciones/grupos + barra de stats)". El título (nombre + número de dex) se conserva porque es la cabecera. Si el usuario quiere eliminar también el título, aclarar.
8. **Punto 4 del usuario ("el titulo no debe tener transparencia")**: el título ya es opaco (placa metálica con `fill`). Si se refiere a que el shader no debe aplicar efectos translúcidos sobre el título, ya está cubierto: `surfaceZone` excluye `layer3.a` del holograma. Si se refiere a la placa metálica translúcida que existía antes, ya fue reemplazada por `metalFill` opaco.
